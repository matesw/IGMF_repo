# IGMF analysis products

This repository contains analysis products used to obtain the results reported in the following draft:

> Matías Sotomayor Webar, Yosef Abed, and Dieter Horns,  
> [*Discovery of femto Gauss intergalactic magnetic fields towards Mkn 501*](https://arxiv.org/abs/2509.11996),  
> arXiv:2509.11996 [astro-ph.HE].

## Contents

- `config_H0yaml.yaml` and `config_H1.yaml`: Fermipy analysis configurations.
- `fermipy_environment.yml`: software environment used for the analysis.
- `input_*`: ELMAG simulation input parameters.
- `simcube_1.58488e-15_002_0.01.fits`: simulated cascade-emission product used in the analysis.

The paths in the YAML configuration files reflect the original computing environment and must be adapted before reuse on another system.

If you use these products, please cite the draft above.
